Privacy policy

What we collect. Admission details that parents send on WhatsApp, attendance, fees, results and behaviour records of enrolled students, and simple visit counts of this website.

How we use it. Only to run the center and to keep parents informed. Parents see their own child's report with the Student ID and the PIN printed on the card. We never sell or share student data.

Student showcase. A student's name, photo or work is published only with the permission of the parent or guardian. Ask the center to remove any item at any time.

Visit counts. We count visits to improve the website. We do not store names, phone numbers or exact locations of visitors.

Import from Excel

Add many teachers, classes and students at once from an Excel (.xlsx) or CSV file. Do the three steps in order. Nothing is saved until you press Import.

The template has three sheets: Teachers, Classes and Students. Fill them in and use the same column names.

1. Teachers

Columns: Name, Subject, Course, Phone, Qualification

2. Classes

Columns: Class name, Course, Batch, Days, Time, Room, Seats, Teacher 1, Teacher 2 (teacher names as in step 1)

3. Students (class wise)

Columns: Name, Father, Gender, Parent phone, Student phone, Class, Address, Last school. Put each class on its own sheet named like the class, or use a Class column, or pick one class below for the whole file.

About Nosaach

Nosaach English Language & Computer Center, R.C Buleda

Nosaach is the first center in R.C Buleda to teach girls and small boys the English language. We have been teaching English since August 2018.

In October 2026, Nosaach took a new step towards technology. To give the students of Buleda the skills that the modern world needs, we started Computer classes for girls and boys, and we have been teaching them ever since.

Our journey

August 2018 · Nosaach opens as the first center in R.C Buleda teaching English to girls and small boys.

Cloud saving

How to get the free cloud URL
  1. Open firebase.google.com and sign in with Google.
  2. Create a project, then Build > Realtime Database > Create database.
  3. Copy the database URL shown at the top and paste it above.
  4. Build > Authentication > enable Email/Password, then add your own admin user (email and password).
  5. Project settings > General: copy the Web API key.
  6. Under Rules, paste this (replace the email with your admin email), then Publish:
    {"rules":{".read":false,".write":false,
"nosaach":{".read":"auth.token.email=='YOUR_ADMIN_EMAIL'",".write":"auth.token.email=='YOUR_ADMIN_EMAIL'"},
"pv":{"$uid":{".read":"auth.uid==$uid||auth.token.email=='YOUR_ADMIN_EMAIL'",".write":"auth.token.email=='YOUR_ADMIN_EMAIL'","inbox":{".write":"auth.uid==$uid"}}}}}
  7. Paste the URL and API key into the two lines at the top of the script (CLOUD_URL_DEFAULT and API_KEY_DEFAULT) so parents' phones can log in.
